## 바꾼 파일

| 파일 | 내용 |
|------|------|
| `wrangler.jsonc` | D1 연결(`env.DB`) 추가. `/api/*`, `/ws`는 항상 Worker 코드가 처리 |
| `schema.sql` (새 파일) | `users` 표(아이디, 비밀번호 해시, salt), `sessions` 표(로그인 토큰) |
| `src/index.js` | `/api/signup`, `/api/login`, `/api/logout`, `/api/me` 추가. `/ws`에서 로그인 확인 |
| `public/index.html` | 로그인·회원가입 화면, 로그아웃 버튼. 닉네임 입력칸 삭제 |

## 보안 정리

| 항목 | 방법 |
|------|------|
| 비밀번호 | PBKDF2-SHA256, 10만 번 반복 + 사람마다 다른 랜덤 salt. 원래 비밀번호는 저장 안 함 |
| 로그인 유지 | 랜덤 토큰을 `HttpOnly`, `SameSite=Lax` 쿠키로 줌. 7일 뒤 만료 |
| 채팅 이름 | 서버가 쿠키로 확인한 아이디만 씀. 브라우저가 보낸 이름은 무시 |
| 다른 사이트에서 접속 | `Origin`을 확인해서 거절 (403) |
| 로그인 실패 메시지 | 아이디가 없을 때와 비밀번호가 틀릴 때 같은 메시지를 보여줌 |

## 실행한 명령어

| 명령어 | 하는 일 |
|------|------|
| `npx wrangler d1 create chat-app-db` | D1 DB 만들기 |
| `npx wrangler d1 execute chat-app-db --local --file=./schema.sql` | 로컬 DB에 표 만들기 |
| `npx wrangler d1 execute chat-app-db --remote --file=./schema.sql` | 실제 DB에 표 만들기 |
| `npx wrangler dev` | 로컬 서버 켜기 (`chat-app` 폴더에서, 창을 닫으면 꺼짐) |
