## 테스트 결과

| 확인한 것 | 결과 |
|------|------|
| 로그인 안 하고 친구 목록 요청 → 401 | ✅ |
| 나 자신, 없는 아이디, 중복 신청 → 오류 | ✅ |
| 상대가 먼저 신청한 경우 → 수락 안내 | ✅ |
| 수락 전에는 친구 목록에 안 나옴 | ✅ |
| 신청한 본인이나 제3자는 수락 못 함 | ✅ |
| 수락 후 양쪽 친구 목록에 나옴 | ✅ |
| 기존 채팅 접속 (로그인 안 하면 401, 하면 연결) | ✅ |
| 사용자가 직접 브라우저로 확인 | ✅ |
